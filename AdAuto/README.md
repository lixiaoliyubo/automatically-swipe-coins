# 抖音极速版广告自动刷工具

这是一个用于自动刷抖音极速版广告赚钱的工具，使用ADB与Android设备通信，并能实时捕获手机屏幕显示在应用窗口中。

## 功能特点

- 自动检测并连接Android设备
- 实时捕获手机屏幕并显示
- 自动关闭广告（点击右上角关闭按钮）
- 自动滑动到下一个视频
- 可配置等待时间
- 操作日志记录

## 使用前提

1. 确保已安装ADB（Android Debug Bridge）并添加到系统环境变量
2. 手机已开启USB调试模式并允许ADB连接
3. 手机已安装抖音极速版应用

## 使用方法

1. 启动应用程序
2. 点击「刷新设备」按钮，查找已连接的设备
3. 从下拉列表中选择设备，然后点击「连接」
4. 设置自动化参数（是否自动关闭广告、等待时间、是否自动滑动）
5. 点击「开始自动刷广告」按钮开始自动化过程
6. 需要停止时，点击「停止」按钮

## 注意事项

- 本工具仅供学习和研究使用
- 长时间使用可
